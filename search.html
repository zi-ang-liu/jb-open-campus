1  探索による問題解決

1.1 学習目標

  • コンピュータがどのようにして「問題を解く」のか，その考え方を知る
  • 探索問題の基本的な考え方を理解する
  • 探索アルゴリズムが，いろいろな現実の問題にも役立つことを知る

1.2 クイズ

田中さんは，法政大学のオープンキャンパスに参加するため，横浜駅から東小金井駅までできるだけ早く行きたいと思っている．

下の図は，電車路線を単純化したものである．頂点は駅，線は駅と駅を結ぶ線路を表し，数値は，所要時間（分）を表す．

横浜駅から東小金井駅まで，最短で到達するための経路はどれか？

  1. 横浜駅 ➝ 新宿駅 ➝ 東小金井駅
  2. 横浜駅 ➝ 東京駅 ➝ 新宿駅 ➝ 東小金井駅
  3. 横浜駅 ➝ 八王子駅 ➝ 東小金井駅
ノート答え 
答え: 横浜 ➝ 新宿 ➝ 東小金井
時間: 55 分

1.3 問題解決の手順

1.4 問題の理解

  • 出発地：横浜駅
  • 目的地：東小金井駅
  • 手段：電車を利用して，駅から駅へ移動する
  • 制約：決められた路線図にしたがって移動する
  • 目標：合計の移動時間が最も短くなるようにする

1.5 モデリング

ノート数学モデル
  • 初期状態：横浜駅
  • 目標状態：東小金井駅
  • 状態空間：駅全体（横浜，新宿，八王子，東京など）
  • 行動：ある駅から別の駅へ移動すること
  • 状態遷移：移動によって駅が変わること
  • コスト：各移動にかかる時間（分）
ヒント数式

この模擬授業では，複雑な数学記号を使わないが，上記の内容を数式で表すと以下のようになる．

  • 初期状態：s_0
  • 目標状態：s_T
  • 状態空間：\mathcal{S} = \{s_0, s_1, s_2, \ldots, s_n\}
  • 行動：a_i \in \mathcal{A}
  • 状態遷移確率：p(s_{t+1} | s_t, a_t)
  • コスト：c(s_t, a_t)
ノート解と最適解
  • 解：初期状態から目標状態へ到達するための一連の行動
    • 横浜駅 -> 東京駅 -> 新宿駅 -> 東小金井駅
    • 横浜駅 -> 八王子駅 -> 東小金井駅
    • 横浜駅 -> 八王子駅 -> 横浜駅 -> 八王子駅 -> 東小金井駅
    • …
  • 最適解：その中で，総移動時間（コスト）が最も少ない経路
    • 横浜駅 -> 新宿駅 -> 東小金井駅（総コストは55分）

上記の言葉を使って，探索は以下のように定義できる．

ノート探索

初期状態から目標状態へ到達するための一連の行動を見つける作業

1.5.1 問題例：8パズル

ノート数学モデル
  • 初期状態：コマの初期配置
  • 目標状態：コマの目標配置
  • 状態空間：考えられる全ての配置
  • 行動：コマをスライドさせること
  • 状態遷移：コマをスライドさせることで配置が変わること
  • コスト：スライドするたびに1のコストがかかる．
    • すなわち，総コストはスライドの回数
    • 総コストの最小 \rightarrow 最短手数
  • 解：初期状態から目標状態へ到達するための一連のスライド

1.5.2 問題例：迷路

ノート数学モデル
  • 初期状態：スタート地点
  • 目標状態：ゴール地点
  • 状態空間：迷路の通過可能な全ての地点
  • 行動：上下左右に移動すること
  • 状態遷移：移動することで位置が変わること
  • コスト：移動するたびに1のコストがかかる．
    • すなわち，総コストは移動の回数
    • 総コストの最小 \rightarrow 最短手数
  • 解：初期状態から目標状態へ到達するための一連の移動
ノート探索問題

最短経路問題，迷路問題，8パズル問題のように，解決するために一連の行動を見つける問題を探索問題と呼ぶ．

1.7.1 アルゴリズムの表現

以上で紹介した探索アルゴリズムは，幅優先探索（Breadth-First Search, BFS）と呼ばれる．次の図に示すように，1，2，3，4の順に探索を行う．

ノート幅優先探索
  1. 初期状態から到達可能な頂点を列挙する．
  2. 幅優先の順番で，頂点を展開し，隣接する頂点を列挙する．
    • すでに探索済みの頂点は除外する．
    • 目標状態に到達した場合，その経路を解として記録する．
    • 目標状態に到達していない場合，探索木に追加する．
  3. 探索が終わるまで，手順2を繰り返す．
  4. 得られた解の中から，コストが最も小さいものを選ぶ．
ノート深さ優先探索

深さ優先探索（Depth-First Search, DFS）は，幅優先探索と同様に，探索木を用いて経路を探索するアルゴリズムであるが，探索の順序が異なる．名前の通り，深さ優先で探索を行う．

1.7.4 アルゴリズムの改善

🤔より効率的なアルゴリズムは？

最良優先探索，ダイクストラ法，分枝限定法などのアルゴリズムは，以下のような工夫を行う．

  • 幅優先で探索するのではなく，何らかの規則を用いて，次に探索する最も望ましいノードを選択する
    • 例えば，コストが最小のノードを選ぶ
  • 探索しなくてもよいノードを除外する
    • 例えば，明らかに最適解ではないノードを探索しない

1.8 プログラミング

上記のアルゴリズムを実装するのは難しそうだが，実は以下のように簡単に実装できる．

from collections import deque


def bfs(graph, start, goal):
    queue = deque([(start, [start])])
    visited = set()

    while queue:
        current_node, path = queue.popleft()

        if current_node == goal:
            return path

        if current_node not in visited:
            visited.add(current_node)
            for neighbor in graph.get(current_node, []):
                if neighbor not in visited:
                    queue.append((neighbor, path + [neighbor]))

    return None

1.10 まとめ

  • 探索は，初期状態から目標状態へ到達するための一連の行動を見つける作業である．
  • 系統的に探索を行うことで，手作業で簡単な最短経路問題や迷路問題を解決できる．
  • 複雑な問題を解くには，コンピュータとプログラミングが不可欠
  • プログラムの設計図がアルゴリズム

1.12 経営システム工学って何？

数理科学で社会の諸問題を解決
社会の様々な分野における意思決定やマネジメント全般の問題に対して、数学や統計学、計算機科学など、数理科学を基礎として解決をはかる立場を「経営システム工学」と呼びます。

– 法政大学 経営システム工学科

  • 研究対象
    • 経営システムを含む，社会の様々な分野における意思決定やマネジメント全般の問題
    • 主に以下の分野を対象とする
      • 生産システム，物流システム，交通システム，経済，金融など
  • 研究手法
    • 数学や統計学，計算機科学など
    • 主に以下の手法を用いる
      • 最適化，シミュレーション，モデリング，データ分析，機械学習，AIなど
